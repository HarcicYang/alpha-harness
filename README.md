# alpha-harness

A lightweight, everything-is-a-module coding agent harness. Design decisions
live in [docs/architecture.md](docs/architecture.md).

## Layout

- `apps/alpha-harness`: the `alpha` binary.
- `crates/`: kernel, protocol, and modules.

## Common commands

```sh
cargo build       # Build
cargo run         # Run
cargo test        # Test
cargo fmt         # Format
cargo clippy      # Lint
```
